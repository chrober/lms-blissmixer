# Enhanced Bliss Similarity and Mixing Quality

**Status:** Moved to the
[Bliss Similarity and Analysis Design](https://chrober.github.io/bliss-similarity-design/)
documentation site  
**Migrated:** 2026-07-14

This design has been split into focused, cross-linked pages and is now
maintained in the public
[`chrober/bliss-similarity-design`](https://github.com/chrober/bliss-similarity-design)
repository. The new site combines the player-neutral `bliss-rs` analysis work
with downstream similarity and mixing design without treating either proposal
as official upstream direction.

This repository remains the implementation context for Lyrion Music Server and
the `chrober/bliss-mixer` integration. Current implementation documentation
continues to live in [ALGORITHMS.md](ALGORITHMS.md),
[METRIC_LEARNING.md](METRIC_LEARNING.md), and
[PATH_INTERPOLATION.md](PATH_INTERPOLATION.md).
